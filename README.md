# Resume and Bio-data Website

A responsive multi-page website built with HTML5, CSS3, jQuery and JavaScript.

## Pages
- `index.html` — Home / introduction
- `resume.html` — Resume with print / Save as PDF button
- `biodata.html` — Personal and academic bio-data
- `contact.html` — Contact form that prepares an email using `mailto:`

## Run locally
Open `index.html` in a browser. An internet connection is needed for the jQuery CDN.

## Customize before submission
1. Replace `Your Name`, initials, sample contact information and education details in all HTML files.
2. Update the skills, projects, hobbies and career objective with accurate information.
3. In `js/script.js`, replace `youremail@example.com` with the email address that should receive enquiries.
4. Add your own photograph if desired; the homepage currently uses a text-based photo placeholder.

## Deploy free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `resume-biodata-website`.
2. Extract this ZIP file and upload all its contents (keep the `css` and `js` folders) to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your website URL will look like:
   `https://YOUR-USERNAME.github.io/resume-biodata-website/`

The contact form is front-end only and opens the visitor's default email app. It does not save messages on a server.
